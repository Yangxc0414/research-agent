一句话，凭什么存在。

六个对象，六个所有权。任何一段都不能由下游“顺手补上”。

  1. 01

    Query → SourceHit / Span

    检索不是“搜到就行”，要留下 query、日期、来源、覆盖回执与可定位的 span。

    Knowledge
  2. 02

    Run → RunCapsule + EA

    结果 claim 只认独立重跑；Work 与 Judge 分离，失败也留下可审计的运行胶囊。

    Execution
  3. 03

    Claim → Evidence

    Evidence 是 claim 的唯一写者；技能与执行只能交 artifact，不能直接写 claim。

    Evidence
  4. 04

    Sentence → Slot

    每句话有槽位；没有绑定的句子可以留在草稿里，但不能进入导出。

    Manuscript
  5. 05

    Gate → Closure / Export

    未解析槽位、stale、冲突、无 EA → ExportBlocked；没有任何旁路。

    Closure
  6. 06

    Sign → Author / PI

    AI 使用、未解决项与限制随包导出；作者/PI 保留最终责任。

    Human

RULES协议
  1. 只传引用，不传长文。下游读 artifact store，不读上一轮对话；避免“传话游戏”。
  2. 一对象一写者。Scout 不写 claim，Builder 不写 EA，Auditor 不改稿；职责越界比模型能力不足更常见。
  3. 证据门禁在 Agent 之外。审计独立于生成；claim 只由 Evidence 创建；导出只由 Closure 执行。
