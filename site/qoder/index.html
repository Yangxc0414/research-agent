MCP / HOST MODEL / HUMAN GATES

Qoder 负责判断与编排，
运行时负责证据与门禁。

Qoder 通过标准 MCP 调用 40 个工具；需要模型判断的环节变成可回放的 host-model turn；每个产物落到 hash 绑定的 artifact。签名、冻结与导出不在 MCP 里，仍在 CLI 由人执行。

打开工作台 看六幕演示 40 个工具

THE LOOP

不是“让模型写完整篇论文”。

是把一次科研拆成可调用的工具、可回放的判断和可阻断的产物。Qoder 能推进，但不能替人签字。

01 / PROPOSEQoder 提出研究问题、idea、实验设计、写作草案；作为 host-model turn 保存 prompt 与回答。
02 / CALLMCP 调用project / run / study / writing / venue 工具；参数校验、路径限制、只读或受控写入。
03 / BIND产物绑定study_sha256、claim 草稿、closure report、审计；数字与设计在同一条哈希链上。
04 / GATE人签G1/G2、claim/closure 签名、publish/export；Qoder 只能停在门前。

Qoder、HTTP 与 Python 共用同一套 schema。

工具表在 research_agent/mcp_tools.py；没有 sign / approve / freeze / publish / export 入口。下面只列关键组。

A REAL CALL

中文期刊检查是一次可复现的工具调用。

输入项目内稿件 JSON，输出 venue-audit-0.1；状态只有 ready_for_human / needs_revision / blocked。

// Qoder → tools/call
{
  "name": "research_venue_audit",
  "arguments": {
    "project_dir": "demo",
    "file": "inputs/manuscript.json",
    "kind": "zh_journal",
    "profile": "zh_core_journal"
  }
}

// result (structural audit, never a submission verdict)
{
  "track": "zh_journal:zh_core_journal",
  "status": "ready_for_human",
  "submission_ready": false,
  "checks": 10,
  "blockers": [],
  "warnings": []
}
检查什么：中文摘要、关键词 3–8、章节、参考文献数量与中文文献、基金/资助、创新/贡献、数据/代码可用性。不检查：创新性、同行评审结论、官方模板页限——这些必须人工核对当年通知。
# same check without Qoder, for humans and scripts
python -m research_agent venue audit --kind zh_journal   --file inputs/manuscript.json --profile zh_core_journal
# grant, with NSSFC anonymity confirmed
python -m research_agent venue audit --kind grant --scheme nssfc   --file inputs/grant.json --anonymous --identity-removed --ai-statement
