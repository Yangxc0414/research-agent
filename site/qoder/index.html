THE LOOP

不是“让模型写完整篇论文”。

是把一次科研拆成可调用的工具、可回放的判断和可阻断的产物。客户端能推进，但不能替人签字。下面按主页《科研持续委托闭环》与《执行与路由架构》投影：授权范围前置、反馈回指触发、目标撤销即停。

授权范围前置 · 主页③：希望证明什么 · 可读取什么 · 哪些动作需人签。收到新事件先做相关性检查，再决定是否进入循环；验收单位是「一段时间内的委托是否被妥善办完（签署 + 核验 + 维护）」，不是单轮回复质量。
01 / TRIGGER识别触发 自动新证据 / CI / 评审 / 邮件先做相关性检查；客户端提出研究问题、idea、实验设计与写作草案，保存为可回放的 host-model turn。
02 / FILTER & CALL两级过滤 + MCP 调用 自动快层程序滤噪 → 慢层语义判候选（主页④）；project / run / study / writing / venue 工具做参数校验、路径限制、只读或受控写入。
03 / BIND & VERIFY产物绑定 + 核验 自动study_sha256、claim 草稿、closure report、审计落在同一条哈希链；外部结果要回执与独立复核后才算完成（主页③ 05）。
04 / GATE人签 人门G1/G2、claim/closure 签名、publish/export；客户端只能停在门前，人只在门禁与验收交互（主页④）。
实线 · 前向 虚线 · 反馈回指触发（改变下一步动作） 红 · 人工门 青 · 自动门 / 内部过滤
↩ 持续负责回路04 未获签署或目标未达成 → 回指 01 重新检查相关性并调整下一步动作，而不是写一段反思文本就结束。跟进未完成项、记忆准入与失效传播都落在这一环。
✕ 默认拒绝两级过滤判定不行动 → 静默丢弃，不产物化、不重试、不写 claim；自动门未过一律走默认出口（主页④）。
⊘ 目标撤销 / 失效立即停止并撤销授权；后续事件不再触发执行单元。这一支不在循环内，是硬停止条件（主页③）。

canonical 门禁映射与主页一致：G1 想法选择 = S3 · G2 设计批准 = S4 · S5b 结果人签 = S5c · G5 闭包签署 = S16；升级人签、降级自动。四个门不可由模型代签，MCP 工具表里没有 sign / approve / freeze / publish / export。本页为静态说明，不发起真实连接。

同一份配置

主流 MCP 客户端都认 mcpServers 这一层结构；克隆仓库后把 --root 指向项目目录即可。密钥与 OAuth 留在 runtime，不写进这份配置。

{
  "mcpServers": {
    "research-agent": {
      "command": "python",
      "args": ["-m", "research_agent.mcp_server", "--root", "."]
    }
  }
}

A REAL CALL

中文期刊检查是一次可复现的工具调用。

输入项目内稿件 JSON，输出 venue-audit-0.1；状态只有 ready_for_human / needs_revision / blocked。

// client → tools/call
{
  "name": "research_venue_audit",
  "arguments": {
    "project_dir": "demo",
    "file": "inputs/manuscript.json",
    "kind": "zh_journal",
    "profile": "zh_core_journal"
  }
}

// result (structural audit, never a submission verdict)
{
  "track": "zh_journal:zh_core_journal",
  "status": "ready_for_human",
  "submission_ready": false,
  "checks": 10,
  "blockers": [],
  "warnings": []
}
检查什么：中文摘要、关键词 3–8、章节、参考文献数量与中文文献、基金/资助、创新/贡献、数据/代码可用性。不检查：创新性、同行评审结论、官方模板页限——这些必须人工核对当年通知。
# same check without a client, for humans and scripts
python -m research_agent venue audit --kind zh_journal   --file inputs/manuscript.json --profile zh_core_journal
# grant, with NSSFC anonymity confirmed
python -m research_agent venue audit --kind grant --scheme nssfc   --file inputs/grant.json --anonymous --identity-removed --ai-statement
