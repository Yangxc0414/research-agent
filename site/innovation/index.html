POSITION / 工程口径与常见科研 Agent 的差异
DeepScientist强在本地工作区/skills/UI我们补 SPEC→artifact/gate 的可读约束
AI-Scientist-v3强在 Docker/run/rubric 单轮我们补 run 之后的证据、claim、稿件槽链
ARIS / AutoResearchClaw强在评审与技能演化我们把审计放进模块契约与工作台
AstraDraw强在参考图→scene→SVG/PPTX我们加 SVG 审计与证据边界

边界：当前是 fixture + CC-BY 论文正文 probe 的纵切；站点没有真实检索 API、用户研究或论文效果数字。受治理 RSI 控制面（StepLedger / pending / lease / MetaTracker）已实现：S1 compare 选中 MiniLM+budget3 并回灌 pipeline；S5 在 iris（seeds 3）与 breast_cancer（seeds 2）上通过 lease 跑真实 run，EA sealed 后由人工签署 claim；ChemLab 真实反应数据做受控 baseline（Ridge R² 0.193 vs mean −0.048）；protocol 冻结、数据图与 DataCite 元数据齐备后 closure 11/11 ready，export manifest 由人签署（submission=false，协议验证而非新发现）。本地 Qwen2.5-0.5B 的 3-prompt 审计 1/3 eligible。仍无可靠开放式 proposer、peer-review benchmark 与真实研究实验，不宣称 RSI。
