THE FOUR JUDGMENTS / 运行时说“不”的四种方式

科研智能体缺的不是生成，是判定。

生成能力到处都有，判定能力没有。全部设计文档把差异收敛为三个判定加一个供给口径——下面每张卡都能在代码里找到对应物，系统地图与六幕推演就是它们逐个发生的样子。

GATES / FALLBACK

门禁没有让步

Q0 / G1 / G2 全部 needs_human；paper 与 experiment 回退 host-agent——S4 设计挂起 host-model 轮次等待人工作答，而不是自动编一份设计；judge 使用确定性模板。

awaiting-host-model.json：「a host answer is capability output, not evidence: gates, audits and signature rules are unchanged」
调用审计只记 provider / model / usage / latency，不记 prompt
INTERCEPT 01 / 统计门槛 3 个种子不够——模型起草的研究被拒

模型草稿沿用 3 seeds，被统计门槛直接拒绝：配对种子 <4 不写任何文件；区间跨零只能如实报“不可判定”，不能靠调阈值圆过去。

INTERCEPT 02 / 设计审计 缺预算字段——S4 设计草稿被退回

模型起草的实验设计漏了 stopping budget，design-audit 以 blocker 拦截、退回人工补齐。模型可以起草，资格检查在运行时。
