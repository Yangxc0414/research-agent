01

本质判断：承接上次讨论的重心转移

上次讨论的五判断与两认知，照出三个本质矛盾。它们决定了我们不该在「生成更多 / 更快」上竞争，而该在「可信 / 可积累 / 可解释」上建立切口。

本质矛盾 ①

生成 ≠ 证据

对应判断 2（产出像论文 → 过程经得起复现）。可验证性分三层：结果复现 / 过程复现 / 证据链复现；其中证据链复现（陈述→数据→代码→执行→分析）基本空白。独立审计发现 AI Scientist 42% 实验失败仍成文；Co-Scientist 扩展审计显示无验证机制时端到端论文严重结果幻觉 ~90%（加可靠性模块降至 ~4%，30 专家/450 评审）。

策略指向：做证据链复现层 + 记忆条目绑定执行契约 / provenance，而非更强生成。

本质矛盾 ②

判定 / 反思 ≠ 行动

对应可证伪问题二与 PerturbTrace：真实反馈并不稳定优于随机 / 无反馈；SAGE 的多假设反思本身已不新。判定消费指把门禁/验证/失效的判定结果用作下一步行动的输入，而非只读报告；关键不是「生成解释」，而是反馈是否按证据质量改变下一步正确行动。

策略指向：把「判定消费为行为」作为切口，用真实/打乱/过时/含噪/矛盾反馈做机制级对照。

本质矛盾 ③

单次成功 ≠ 可积累增益

对应判断 1（程序自主 → 过程自主）与问题一/三：一次修复成功不代表学会；反复按同一指标选最优会高估科学进步（Goodhart）。记忆准入要看学习证据：跨任务迁移 / 知识保留 / 退化检测 / 演化成本。

策略指向：学习证据四维准入 + 负迁移控制；度量借外部成熟信封，不发明度量。

前置认知 A · 个体新颖 ≠ 群体多样 37,802 条 AI 构思研究（上次纪要，待核）+ Si et al. 互证：想法「个体新颖、群体趋同」，多为局部方法重组。Evidence-Informed Beliefs 已在做多样性优化 → 新工作必须聚焦长时程探索中的具体失效条件，而非泛泛「增加多样性」。
前置认知 B · 评测能测结果，不一定解释能力升降 MLR-Bench / ScienceClaw-Eval 已支持阶段级与演化级评测 → 不能再笼统把「缺评测」当选题。必须针对具体机制提出可证伪评测问题（见 §05 四问）。
02

我们目前希望采用的策略（而非已做了什么）

以下四条是拟采用的研究策略，对应上次两主线与三方向。它们是「打算怎么研究」，不是「已经实现了什么」；每条都带一个可证伪的验证入口。

策略① · 主线一 / 方向 B

过程可信底座：三层可验证 + 证据溯源

以证据链复现为核心：论文每个实验性结论可追溯到数据 / 代码版本 / 执行记录 / 分析过程；结果变化时能识别哪些图表、统计、陈述失去支持。记忆条目绑定执行契约与 provenance，配类型化记忆图谱 + 协调协议（四类记忆：文献关系 / 领域知识 / 假设证据 / 执行技能）。

验证入口：held-out 改上游 code/data/protocol，测失效推导是否正确（对照只防篡改不传播失效的系统）。

策略② · 判定消费 / 问题二

反馈 → 行动：让判定改变下一步决策

研究「实验反馈在什么条件下真正改变正确行动」，而非只写反思文本。对同一任务提供真实 / 打乱 / 过时 / 含噪 / 互相矛盾反馈，比较下一步行动是否按证据质量合理变化。互操作协议记录「角色—评审—消费—复验」关系（判断 4）。

验证入口：反馈敏感性与反馈真实信息价值是否一致；显式识别反馈质量能否改善行动选择。

策略③ · 方向 A / 问题三

学习证据准入：技能适用域与负迁移控制

不研究「生成更多技能」，而研究已验证技能何时可安全用于新任务：直接复用 / 先行测试 / 拒绝复用。准入不看单次复验，看四维学习证据（迁移 / 保留 / 退化 / 成本）。对照 ScienceClaw 三重验证、AutoSci 持久记忆，找其筛选机制处理不了的情境变化。

验证入口：全部存储 / 全不存储 / 重放后存储 / 独立任务验证后存储 四策略对照跨任务收益。

策略④ · 主线二 / 方向 C

多样性保持 + 反事实证伪 / 信念修订

监测群体同质化、带多样性约束的探索奖励；补因果干预 / 反事实证伪（T6 空白最大）；证据冲突时决定修订信念 / 保留不确定 / 再激活被否决假设。需构造能区分「合理修订」与「无效反复探索」的评测环境。

验证入口：跟踪多轮方向分布 / 新颖度 / 重复率 / 可验证收益，对照有 / 无探索约束。

策略取舍（有所不为） 不追端到端生成红海——质量证据差（42% 失败 / ~90% 幻觉）且赛道拥挤，正面竞争无差异化；不发明度量——ARS/CCFA/MLR-Bench 已把度量做成机器契约，再发明不被认新颖，故借信封对准空白；不搬全量 skill 目录——AJS 证明静态格式≠运行时证据，搬目录不增可信；不引入无约束 autonomous execution——ARS 明确拒绝、安全/隐私开放问题未解； 人工门留在高杠杆节点（假设选择 / 设计批准 / 签署），自动化只跑门间段。新颖性锁定在外部集体空白：证据链复现、失效传播、判定消费、学习证据准入。
与上次三方向的对应 方向 A（技能适用域）→ 策略③；方向 B（实验→陈述证据溯源）→ 策略①；方向 C（信念修订 / 假设再激活）→ 策略④（主体）；策略②为其提供「修订是否真的改变行动」的判据。 倾向以 B 为内核守住、A 为第一个切口（上次优先推荐）、C 为后续前沿；策略②贯穿作为「反馈是否改变行动」的诊断实验。

05

三个优先方向 + 四个可证伪评测问题

承接上次讨论：方向 A/B/C 是战略选项，四问是把它们落成「能失败」的实验。优先顺序与上次一致：A 优先、B 守内核、C 后续；问题二作第一个诊断实验、问题一优先预实验。

方向 A

技能迁移的适用域判定（优先推荐）

切口 · 负迁移控制

一个历史任务上验证过的技能，在什么条件下可安全用于新任务？何时直接复用 / 先行测试 / 拒绝复用？

对照已覆盖ScienceClaw 重放 + 独立任务验证；AutoSci 持久记忆。泛泛「该不该写 Memory」已不新。 新切口学习证据四维准入（迁移/保留/退化/成本）+ 其筛选机制处理不了的情境变化 / 错误迁移案例。 最小实验成功经验集在原任务/相似/分布变化任务上测；四存储策略对照。
方向 B

实验运行 → 论文陈述的证据溯源（守内核）

内核 · 证据链

每个实验性结论能否追溯到数据 / 代码版本 / 执行记录 / 分析过程？结果变化时识别哪些图表 / 统计 / 陈述失去支持。

对照已覆盖PaperBench 结果复现、REPRO-Bench；但证据链复现层空白。 新切口不是加事实核查 agent，而是失效传播：upstream-change→downstream-stale。 最小实验held-out 改上游，测哪些结论/图表被正确判失效、哪些需重签、导出是否被锁。
方向 C

证据冲突下的信念修订与假设再激活（后续前沿）

前沿 · 需评测环境

新证据与历史结论冲突时，如何决定修订信念 / 保留不确定 / 再激活被否决假设？

对照已覆盖AutoDiscovery 贝叶斯惊奇度；Evidence-Informed Beliefs 动态信念。 新切口构造能区分「合理修订」与「无效反复探索」的评测环境（FalsifyBench 子集）。 风险更前沿但评测环境构造成本高，适合作后续工作。

四个可证伪评测问题（机制级，非笼统「缺评测」）

问研究问题 / 可证伪假设最小实验优先级 / 风险
Q1连续优化后指标收益是否与独立科学证据脱钩？假设：反复筛选使报告指标改善而独立验证停滞。多 agent 固定预算反复改进同批任务，记录优化指标 vs 独立种子/独立条件结果，看差距随轮次扩大。优先预实验；需证明是长期反复选择的系统偏差，非普通测试集已知问题。
Q2什么情况下实验反馈真正改变正确行动？假设：反馈敏感性与真实信息价值不一致。同一任务给真实/打乱/过时/含噪/矛盾反馈，比较下一步行动合理变化与最终结果。第一个诊断实验；易启动但与近期工作重叠高。
Q3怎样判断一次成功修改值得沉淀为长期经验？假设：原任务成功不足以预测跨任务收益。四存储策略（全存/全不存/重放后/独立验证后）对照跨任务收益。与主线一致；作后续或 Q1 机制扩展。
Q4自主循环是否越来越擅长局部改进却难跳出既有路线？假设：探索空间逐步收窄。跟踪多轮方向分布/新颖度/重复率/可验证收益，对照有/无探索约束。重要但不作第一篇主切口。

术语速览（便于口头表述）

判定消费：把门禁/验证/失效的判定结果用作下一步行动的输入，而非只读报告。

三层可验证：结果复现 / 过程复现 / 证据链复现（陈述→数据→代码→执行→分析）。

学习证据准入：记忆/技能写入前看跨任务迁移、知识保留、退化检测、演化成本四维，而非单次复验。

provenance / 证据链：每条结论与记忆条目绑定来源与执行契约，上游变更可推导下游失效。

fail-closed：缺证据/缺授权时默认拒绝，而非默认放行。

Router / Worker：控制面（协调/交互/记忆、不执行）与执行面（隔离上下文、并发）分离。

Thread：同一研究问题/claim 的事件流；已订阅的后续事件直通负责 Worker，不重跑全流水线。

供给独立：生成与评审来自不同供给方（跨模型/跨 worker），避免「自己生成自己批准」。

Goodhart：按同一指标反复选最优，会使报告指标与真实科学进步脱钩。
