## 一、五个核心判断：研究重心的转移

当前自主科研智能体的能力增长，正在把研究焦点从"**能不能做**"推向"**做了之后是否可信、是否可积累、是否可解释**"。以下五组判断构成后续所有方向的前提。

### 判断 1｜程序自主 → 过程自主

一次修复成功，不代表智能体真正学会了。**记忆准入不能只看单次结果复验**，要看"学习证据"：

- 跨任务迁移
- 知识保留
- 退化检测
- 演化成本

> 对照：ScienceClaw 已要求技能修复通过重放 + 独立科学任务验证；AutoSci 已将持久记忆与反馈驱动演化放入统一系统。泛泛研究"该不该写入 Memory"已不新，关键在**准入证据的类型与门槛**。

### 判断 2｜产出像论文 → 过程经得起复现

能产出科研成果，不等于产出了可信的科学证据。**可验证性要分三层**：

| 层级 | 含义 | 当前缺口 |
| --- | --- | --- |
| 结果复现 | 同一输入能否得到同一输出 | PaperBench 已量化"复现鸿沟"（最优系统约两成） |
| 过程复现 | 执行路径、代码版本、参数是否可重建 | 过程级评测缺失 |
| 证据链复现 | 论文陈述能否追溯到数据→代码→执行→分析 | 证据溯源账本基本空白 |

**记忆条目须绑定执行契约与可溯源**——否则记忆只是不可审计的文本堆叠。

### 判断 3｜因果模型、干预、反事实推理仍然脆弱

现有系统在"**如果换一个条件会怎样**"的反事实推断上能力薄弱。这直接制约两个方向：**证伪实验规划**与**证据冲突下的信念修订**。T6（科学验证、证伪与复现）被标记为三大层中**空白最大的模块**——检索未发现"以可证伪性为一等约束"的科研 agent 论文。

### 判断 4｜多智能体：功能分化，而非数量堆叠

多智能体架构的价值在**功能分化**，不在 agent 数量。**互操作协议要记录"角色—评审—消费—复验"关系**，否则只是 agent 堆叠。

> 对照：AutoSci 的 SciDAG 明确"无需依赖一个智能体思考复杂问题"，按阶段难度动态切换粒度；AutoResearchClaw 用 HITL 把人的判断嵌入高杠杆节点。两者都在做**结构化分工**，而非简单 swarm。

### 判断 5｜科研记忆丰富，但类型间协调不清

现有路线分别积累四类记忆：

1. **文献关系**（Chain of Ideas、SciNet）
2. **领域知识**（Kosmos world model）
3. **假设与证据**（Evidence-Informed LLM Beliefs）
4. **执行经验/程序性技能**（ScienceClaw 300+ skill、SkillFoundry）

四类并存但**互不兼容、无统一本体**。主线核心不是"统一字段"，而是**类型化记忆图谱 + 协调协议**。评测不能笼统说"缺"，要做**机制级可证伪评测**。

## 二、两个前置认知：同质化与评测的边界

### 认知 A｜个体新颖 ≠ 群体多样

对 **37,802 条 AI 生成科研构思**的研究发现：现有科研智能体生成的想法**更集中于已有研究，更多表现为局部方法重组**，而非开辟全新研究问题。Si et al.（ICLR 2025）的人评结论互证——"个体新颖、群体趋同"。

与此同时，Evidence-Informed LLM Beliefs 已开始研究**随证据演化的探索奖励和多样性优化**。这意味着"如何增加多样性"已有直接研究，新工作必须聚焦**长时程探索中的某个新机制或具体失效条件**。

### 认知 B｜评测能衡量结果，但不一定解释能力升降

- **MLR-Bench** 已支持研究阶段级与最终成果级评测。
- **ScienceClaw-Eval** 进一步考察持续演化、知识保留、跨数据集迁移和演化成本。

因此，**不能再笼统把"缺乏科研智能体评测"当作新选题**。更重要的是针对具体机制提出**可证伪的评测问题**。

**关键词**：类型化记忆图谱 + 协调协议 + 学习证据准入 + 三层可验证 + 执行契约/provenance + 机制级评测

| 交付物 | 说明 |
| --- | --- |
| 类型化记忆图谱 schema | 四类记忆：文献关系、领域知识、假设与证据、执行经验/程序性技能 |

## 四、三个优先方向

### 方向 A（优先推荐）｜技能迁移的适用域判定

**标签**：科研智能体 · 持续自进化 · 负迁移控制

**研究问题**：一个历史任务上经过验证的技能，在什么条件下可以安全地应用于新任务？

**转向**：不再研究"怎样让 Agent 生成更多技能"，而是研究**怎样判断某个技能在当前任务中是否仍然适用**——何时直接复用、先行测试，或拒绝复用。

> 与主线一的关系：这是"学习证据准入"在技能维度的具体化，直接对应判断 1。

### 方向 B｜从实验运行到论文陈述的证据溯源

**标签**：科研可信性 · 证据链 · 结果可复现

**研究问题**：论文中的每一个实验性结论，能否追溯到实际数据、代码版本、执行记录和生成它的分析过程？

**重点**：不是增加一个事实核查 Agent，而是**使实验结果变化时，能够识别哪些图表、统计结果和论文陈述已经失去证据支持**。

> 与主线一的关系：这是"三层可验证"中证据链复现层的核心机制，直接对应判断 2。

### 方向 C｜证据冲突下的科研信念修订与假设再激活

**标签**：科研记忆 · 持续发现 · 不确定性

**研究问题**：当新证据与历史结论冲突时，智能体如何决定修订已有信念、保留不确定性，或重新探索过去被否决的假设？

**判断**：更前沿，但**需要构造能够判断"合理修订"与"无效反复探索"的评测环境**。

> 与主线二的关系：这是反事实推理与信念更新在记忆层的交汇点，直接对应判断 3 与判断 5。

## 五、四个可证伪评测问题

### 问题一｜连续优化后，指标收益是否会与独立科学证据脱钩？

**研究问题**：当 Agent 反复修改代码、试验方法、按同一验证指标保留最优结果时，报告中的指标提升是否会越来越乐观，但独立复现或稳健性检验没有相应改善？

**为什么值得关注**：`autoresearch` 把修改→执行→指标反馈→保留/回滚连成闭环；RewardHackingAgents 已研究评估器篡改与训练—测试泄漏；FIRE-Bench 已研究可验证科学发现。现阶段要研究的**不是再防一次作弊**，而是：**评估环境没有被篡改时，反复选择最优结果是否仍会造成对科学进步的高估**。

**最小实验**：多个 Agent 在固定预算内反复改进同一批任务，同时记录优化指标与独立随机种子、独立测试条件下的结果，观察两者差距是否随迭代轮次扩大。

**可证伪假设**：随着反复筛选次数增加，最优报告指标持续改善，而独立验证收益趋于停滞。

**主要风险**：保留集评估与结果选择偏差已有相关工作；2026 年一项实证经济学研究已将 AutoResearch 式迭代搜索与搜索后留出集评估结合。需证明研究的是**长期反复选择带来的系统性偏差**，而非重复使用普通测试集的已知问题。

**初步判断**：较值得优先开展预实验。能否成文取决于能否观察到**现有防护无法解释的稳定现象**。

### 问题二｜什么情况下，实验反馈才能真正改变 Agent 的正确行动？

**研究问题**：Agent 收到新实验结果后，究竟是根据证据调整了研究决策，还是只在反思文本中解释了结果，而实际行动并未发生合理变化？

**为什么值得关注**：PerturbTrace 已发现**真实反馈并不稳定地优于随机反馈或无反馈**，说明最终任务成绩不能充分代表反馈利用能力。SAGE 已提出多假设失败归因，因此"生成多个原因并反思"本身不能再作为创新。

**最小实验**：对同一研究任务分别提供真实、打乱、过时、含噪、互相矛盾的反馈，比较 Agent 下一步行动是否按证据质量发生合理变化，以及最终结果是否改善。

**可证伪假设**：现有 Agent 对反馈的敏感性与反馈的真实信息价值并不一致；对反馈质量进行显式识别，可能改善行动选择。

**主要风险**：已有工作直接研究反馈使用与失败归因。新贡献必须定位到**尚未覆盖的反馈条件**，或展示跨多轮研究中反馈效应如何变化。

**初步判断**：实验容易启动、现象容易观察，但与近期工作重叠较高，适合作为**第一个诊断实验**。

### 问题三｜怎样判断一次成功的修改，值得沉淀为长期科研经验？

**研究问题**：某次修复在原任务中有效，但换了数据、假设或执行条件后可能失效。Agent 怎样区分可复用的科研经验和只适用于局部情境的偶然修复？

**为什么值得关注**：AutoSci 已将持久记忆、科研工作流和反馈驱动演化放入统一系统；ScienceClaw 已要求技能修复通过重放和独立科学任务验证。因此泛泛研究"该不该写入 Memory"并不新。

**最小实验**：建立成功经验集，在原任务、相似任务、分布变化任务上测试；比较**全部存储 / 全部不存储 / 重放后存储 / 独立任务验证后存储**四种策略。

**可证伪假设**：单纯的原任务成功不足以预测长期经验的跨任务收益；利用适用条件和负迁移信号，可能改善经验复用。

**主要风险**：ScienceClaw 已覆盖跨任务验证。必须找到**它现有筛选机制无法处理的情境变化或错误迁移案例**。

**初步判断**：与长期研究主线一致，但更适合作为后续工作，或作为问题一的机制扩展。

### 问题四｜自主科研循环是否会越来越擅长局部改进，却越来越难跳出既有路线？

**研究问题**：当 Agent 持续基于已有文献、历史结果和优化反馈寻找下一步方案时，探索空间是否会逐步收窄，导致系统不断优化主流方向，却很少考虑真正不同的研究问题？

**为什么值得关注**：AI Research Agents Narrow Scientific Exploration 已通过 37,802 条生成想法研究科研探索收窄；Evidence-Informed LLM Beliefs 已研究动态信念更新与探索多样性。

**最小实验**：跟踪多轮构思和实验中的研究方向分布、新颖程度、重复率、最终可验证收益，比较普通迭代与具有明确探索约束的策略。

**主要风险**："AI 想法趋同"及"如何增加多样性"已有直接研究。必须聚焦**长时程探索中的某个新机制或具体失效条件**。

**初步判断**：问题重要，但**目前不建议作为第一篇工作的主切口**。

## 七、科研智能体 Taxonomy 树（三大层次）

### 一、任务能力层（能做什么？）

#### T1 文献检索与关系推理

**SciNet: Evaluating AI Agents in Relation-Aware Scientific Literature Retrieval**（ICML 2026）（benchmark）（关系感知的文献检索评测 benchmark）

**SAGE：One Reflection Is Not Enough: Self-Correcting Autonomous Research via Multi-Hypothesis Failure Attribution** — 把单次自我反思重构为多假设失败归因：失败后同时生成多个候选原因、对关键假设逐一验证、再把修复路由到对应环节。

**OpenScholar: Synthesizing Literature with Retrieval-Augmented Language Models**（AI2 / UW，2026-02 更新）
开源的科研文献**综合模型 + 数据管线**，强调**可验证引用**；与闭源 Deep Research 对打的开放基线。

**PaperQA2**（FutureHouse）
高精度科研 RAG agent：把**检索与作答**当作多步 agent 任务；配套论文《Language agents achieve superhuman synthesis of scientific knowledge》宣称在文献综合任务上超人类专家。定位：当前"读文献"能力上限的事实参照。

**SciArena: An Open Evaluation Platform for Non-Verifiable Scientific Tasks**（AI2，2025）
科研文献问答的"竞技场式"**众评平台**（约 1700 名研究者、3900+ 票），解决无法自动判分任务的评测问题。

#### T2 假设生成与开放式探索

**IdeaScientist: Orchestrating Agents for Grounded Scientific Ideation**（Jiarui Liu et al. · arXiv:2610.04074）
在暂时不执行实验的条件下，能否**根据一个明确的研究问题和现有方法的不足**，提出有文献依据、具有**新颖性且能够被验证**的研究方案？（基于**跨领域**机制迁移的科研构思）将 ideation 分解为 gap finding → innovation → report writing 三个 RL 训练的专职子智能体，产出有文献依据的研究方案。核心研究问题（初稿已写）：不执行实验的条件下，能否针对明确研究问题产出**有依据、新颖、可验证**的方案（跨领域机制迁移）。

**ResearchAgent**（从一篇基础论文出发，结合学术图 + 概念知识库检索相关文献，ReviewingAgent 评审）

**Chain of Ideas** — 一条条发展脉络理解一个领域：谁在谁的基础上提出了什么改进，下一步可能走向哪里。将文献组织为**链式结构**，在线时让 LLM 沿链迭代判定相关性。

**AIM: Agentic Idea Management for Automated Research**（idea-driven search（想法驱动搜索））— 想法驱动搜索与解驱动搜索区分，结构化管理，基于事实的自适应想法筛选、可靠的想法—方案对齐（贝叶斯优化代理模型 + 采集函数）。

**AutoDiscovery**（NeurIPS 2025）（用贝叶斯惊奇度作为目标函数 + MCTS 在巨大假设空间搜索，把 LLM 的"探索欲"作为形式化目标）

**Evidence-Informed LLM Beliefs for Continual Scientific Discovery**（arXiv:2606.29182，2026-06）
**长时程假设搜索循环中维护**显式信念分布，用累积证据持续更新 LLM 对假设空间的先验（作者与 AutoDiscovery 同组，是其"记忆化"续作——**在搜索循环外部维护一个随证据演化的信念状态，让 LLM 的先验"记住"历史，从而让"什么值得探索"这个判断随时间越来越准**）。

**SAGA: Accelerating Scientific Discovery with Autonomous Goal-Evolving Agents**（arXiv 2025-12）
自主目标演化：自动完成高层目标分解→规划→迭代的科学发现流程，在化学等多域验证。

**PiEvo / FlowPIE 类工作**（2026-03）
初稿条目 PiEvo 与 FlowPIE（test-time idea evolution，检索-生成共同演化）、Idea-Evolution（长程 ideation 的结构化表示）同属一族；建议合并标注为"**测试时想法演化**"分支，待补准确出处。

**AI Research Agents Narrow Scientific Exploration**（arXiv 2026-07）（**关键反面证据**）
多框架 × 多模型生成 3.7 万+条 AI idea 的大规模实证：**AI 生成想法使科学探索收窄、趋同并强化既有主流方向**。与 Si et al. 2024（ICLR 2025）"个体新颖、群体趋同"的人评结论互证——这是 T2 路线最核心的未解问题。

**Can LLMs Generate Novel Research Ideas? A Large-Scale Human Study**（Si et al., ICLR 2025）
100+ 专家盲评：LLM idea 的 novelty 评分高于人类专家写出的 idea，但多样性显著更低、内部趋同。novelty ≠ diversity 的经典证据。（受控评估框架 + 检索增强科研 idea Agent）

**BioDiscoveryAgent**（arXiv 2025-03）

#### T6 科学验证、证伪与复现

**（空白提示）证伪（falsification）方向**：检索未发现"以可证伪性为一等约束"的科研 agent 论文——T6 是三大层中空白最大的模块。

#### T7 成果生产与学术交流（论文、图表）

### 二、系统组织层（怎么组织？）

#### T1 端到端与闭环科研自动化

**Denario**（Simons Foundation，arXiv 2025 + APS Phys. Rev. 2026 教程）
面向天体物理的多智能体全流程系统（idea→文献核查→代码开发→结果解释），学术界自建（非公司）的代表。

**Kosmos: An AI Scientist for Autonomous Discovery**（arXiv 2025-11，FutureHouse）
核心创新是 **world model**：以结构化世界模型为中心组织知识，单次运行可达 12 小时的并行文献检索 + 数据分析 + 假设生成循环。"领域世界模型"是 L3-T2 的重要形态。

**Robin**（Emerald Cloud Lab 系）：商业端云实验室 + 闭环执行。

**Deep Research in Physical Sciences: A Multi-Agent Framework**（arXiv 2026-06）**[✓]**
将"深度研究"式多步推理 agent 引入物理科学。

让多智能体在**公开悬而未决的科学问题**上协作竞争、共享部分结果、以精确/近精确验证评分——从"benchmark"走向"持续运行的竞技场生态"。

**Agent Laboratory: Using LLM Agents as Research Assistants**（AMD，arXiv/ACL 2025）
从人类给定 idea 到成稿的全流程自动化框架，研究者问卷评测 + 显著降本；"人给 idea、agent 做研究"的半自动形态代表。

**Autonomy Levels for Agentic AI**（Cloud Security Alliance，2026-01）

**（空白提示）** 尚无"科研专用"自治刻度（区分湿实验/干实验/投稿等风险等级并与验证义务挂钩）。

**From Prompts to Protocols**（arXiv 2026-05）
自然语言 → 可执行实验协议的实验室编排 agent（LLM + 实验室中间件）。

**AutoLabs**（Nature 2026）：多智能体编排 + 商业硬件的完整案例。

**ScienceClaw: Autonomous Agents Coordinating Distributed Discovery**（arXiv 2026-03）
跨生物/化学等域 300+ 可互操作工具的分布式发现编排。

**（空白提示）** 跨机构算力/实验资源的"市场化调度"、长时程预算控制、任务优先级仲裁基本空白。

### 三、基础设施层（怎么设计？）

#### T1 科研评测与验证

- 已核实：**PaperBench**（复现）**[✓]**、**MLE-bench**（ML 工程）**[✓]**、**MLR-Bench: Evaluating AI Agents on Open-Ended ML Research**（NeurIPS 2025 D&B，arXiv:2505.19955）**[✓]**（开放式研究三组件评测：任务集+过程评测+判分）、**REPRO-Bench [✓]**、**AstaBench**（AI2，2025-08）**[✓]**（严格化的科研 agent 评测框架与套件，复用 SciCode/MLE-bench 等）、**ScienceAgentBench**（ICLR 2025，arXiv:2410.05080，~373 引）**[✓]**（数据驱动发现 102 任务 + 严格成本控制 + solvable 设置）、**DiscoveryBench / DataSciBench / SciNet / EinsteinArena / SciAgentArena**（单细胞/空间组学/药物发现等生信任务）**[✓]**。

- **（空白提示）** 过程级（推理轨迹而非终态制品）与长周期（月级任务）评测缺失；LLM-as-judge 缺校准协议。

#### T2 科研记忆与知识复用

- **Chain of Ideas**（文献链 = 外部知识记忆）
- **Kosmos**（world model = 领域结构化知识记忆）
- **Evidence-Informed LLM Beliefs**（信念分布 = 证据记忆）
- **ScienceClaw**（300+ skill = 程序性记忆）

四类"科研记忆"并存但**互不兼容、无统一本体**（这是本层的核心问题，也是机会）。

**SkillFoundry: Building Self-Evolving Agent Skill Libraries**（arXiv 2026-04）
树引导的领域技能库自动构建与维护框架。

**Paper2Agent / MUSE-Autoskill / Memory 三部曲综述 [U]**：初稿条目；最后者建议锚定 LLM agent 记忆机制系列综述（存储/读写/管理三视角）。

#### T3 持续自进化与适应

**ScienceClaw: Benchmarking Continual Self-Evolution of AI Agents**（arXiv:2610.08691，2026-10）
验证驱动的技能沉淀流水线：可复现修复 → 关联的 Skill–Operator 更新；以可复现性 / 跨任务收益 / 科学约束**三重验证**作为沉淀门槛。当前"自进化"方向最完整的公开工作。

**SkillFoundry**

**AutoResearchClaw**（GitHub，开源）
全自主 + 自进化框架：单一研究想法 → 会议级论文成品；支持按学科加载开源/自定义技能。

**演化工程树 / Trigger-conditioned, RCA-grounded Evolution [U]**：初稿条目（RCA 根因触发的进化机制，待补出处）。

**SwarmRSI**：通过进化科学智能体蜂群实现递归自我改进。

**2026 RSI / 自进化家族（新增，完整对照见 [`10-`](10-RSI与自进化反思-科研改进的准入与证据闭合.md)）**

- **Dream-RSI**（arXiv:2609.14858，2026-09）：从历史发现树构建可演化世界，在线探索 + 离线模拟更新探索策略，不更新权重；评估 9 任务/4 域。
- **Karl Workbench / RSD**（无界进化，2026-09）：记录、积累、产物、监督、进化五层；研究状态含结论、证据、失败路径；**只有厂商/媒体口径，本轮未找到论文**。
- **RSIAgent**（arXiv:2609.15364，2026-09）：curriculum–actor–verifier 三角色，先广后深（BRS/DRS），外部记忆在测试时冻结，不更新参数。
- **MASS**（arXiv:2610.12176，2026-10）：同基座模型分饰 executor / optimizer / evaluator，内循环搜索工作流、外循环蒸馏；作者报告 1.2–1.6× 每 token 得分，但 SWE-bench / Terminal-Bench 为 0.94–0.96×。
- **SkillCAT**（arXiv:2606.13317，2026-06）：CCE 对比成功/失败轨迹、AAE 评估进化、TTE 拓扑路由；验证主要在源任务克隆。
- **两篇综述**：Self-Evolving Agents（arXiv:2507.21046，TMLR 2026；What/When/How/Where）与 RSI 综述（arXiv:2607.07663；1,250 篇，改进对象 × 闭环程度）。
- **判断**：这些工作优化的是策略、状态、记忆、工作流、技能或 harness；共同缺口是**独立判定、改进准入、证据链闭合、责任链**。它们属于邻近赛道，不改变本组主线一/二的选择；我们的接入点是"准入层 + 证据层"，不是再做一个 RSI 循环。

#### T4 科研可复现性、证据溯源与治理（可信性、验证）

- **Agentic Economies**：初稿条目（智能体经济/治理叙事，待补出处）。
- **（真实案例，本周检索发现）** Nature 于 2026-01 对高引 robot chemist 论文发布更正（C&EN 报道）——自主实验论文的可复现性问题已出现公开事故，治理需求是现实的而非假设的。
- **（空白提示）** 证据溯源账本（evidence ledger）、人机贡献归因、AI 生成内容的投稿政策均无技术方案。

#### T5 科研领域与运行环境

- **ToolUniverse**（Harvard Zitnik Lab，2025；现聚合 600+ 工具）：生物医学工具生态 + MCP 协议 + 配套 TxAgent/Medea 等。

- **（空白提示）** 跨域统一环境协议（MCP 化进行中但碎片化）；湿实验仿真环境（安全的 sim2real）缺失。

#### T6 科研数据、知识与工具基础设施

**ToolUniverse**（标准化 AI 模型调用科研工具方式的开放生态）

**OpenScholar**（**4500 万篇**开放获取论文的数据库）（开放数据 + 训练管线）

**PaperQA2**（高精度科研 RAG 底座）
专注于**科学文献**的**高精度检索增强生成（RAG）工具包**，被设计为处理科学论文的最佳智能体 RAG 模型。

**SciArena**（人类偏好数据）
SciArena 是一个**开放、协作的评估平台**，采用类似 **Chatbot Arena 的人类偏好投票**方式，评估基础模型在科学文献任务上的表现。

**AutoSDT-5K**（发现类任务数据集）
用于数据驱动科学发现的自动收集编码任务数据。

- **任务数量**：包含 **5,404** 个科学编码任务。
- **学科覆盖**：横跨**四个科学学科**：生物信息学、计算化学、地理信息科学、心理学与认知神经科学。
- **工具多样性**：使用了 **756** 个独特的 Python 包。

**SciNet**（1800 万论文关系图，首个系统性评估 AI 智能体在大型科学网络中进行关系感知检索能力的综合数据集）

1. **自我中心关系**：评估论文的**新颖性**（非典型知识组合）或**颠覆性**（范式转移）。
2. **成对关系**：识别论文对之间的**引用情感**（支持/批评/中立）或**共提及**关系。
3. **路径关系**：重建从基础概念到最新方法的**科学思想演化轨迹**。

### 1. karpathy/autoresearch ⭐97.9k（2026-03）

仅 **630 行 Python 代码**，精简。对于 **修改代码 → 跑实验 → 看指标 → 保留/回滚** 的科研闭环，让 agent 自行进行：

- **`prepare.py`（固定层）**：数据与分词器准备，**AI 永不触碰**，保证实验起点公平。
- **`train.py`（探索层）**：**AI 唯一可编辑**的文件，包含完整的 GPT 模型、优化器和训练循环。
- **`program.md`（控制层）**：**人类唯一需要编辑**的文件，用自然语言为 Agent 编写研究指令和上下文。
- **目标必须可量化、修改空间必须受限、判断标准必须固定。**
