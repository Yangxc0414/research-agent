## 第 1 页 · 一句话定位（30 秒）

**这学期做的不是"自动写论文的 agent"，是一个证据闭合的科研运行时：对每句结论回答四个判定。**

| 判定 | 问题 | 机制 |
| --- | --- | --- |
| 资格 | 这句话有资格写吗 | span-only：摘要只是线索，全文定位到句才成证据 |
| 完成 | 这次运行能签吗 | RunCapsule → EA → closure 11 项检查 → 作者签署 |
| 失效 | 输入变了谁失效 | lineage：哈希入图，变更传播 stale，旧签名作废 |
| 供给 | 模型草稿能信到哪 | host-as-model：生成可移植，证据资格不可移植 |

**怎么讲**：别人优化生成得多快；我们优化"变更之后哪一句还成立、哪个导出必须被拦"。
对照系：DeepScientist 强在工作区/UI，AI-Scientist-v3 强在单轮 run/rubric，ARIS 强在评审演化——它们各占一个判定，我们用同一套产物身份把三个判定连起来，并让"拒绝"成为默认行为。

## 第 3 页 · 闭环全景（本页最重要，2 分钟）

一条流水线，四道判定，两种"停"：

```
S1 文献 ──→ Q0 ──→ S2–S3 假设 ──→ G1 ──→ S4 设计 ──→ G2 ──→ S5 运行 ──→ S6 图 ──→ S8 稿件
[资格J1]  可否证?   [供给J4]      人工    design-audit  人工   RunCapsule    双哈希   结果槽pending
                             (needs_human)  ⛔真拦截            → EA 封存            等 EA
                                                                    ↓
                                              Claim（作者签署）→ Closure（11 项检查）→ G5 导出
                                              [完成J2]                                [人签]

  ↺ 失效环：任一节点输入变更 → lineage 依赖图传播 stale → 旧签名作废、EXPORT BLOCKED   [失效J3]
  ↺ 改进环：复盘 → 候选改进 → 领租约(scope+TTL) → 真实 evaluator → 人签准入 / 自动撤销
```

**怎么讲**：链上每一环都有 artifact 和门禁；"停"分两种——**设计内的人工门**（G1/G2/签署）和**运行时拦截**（统计门槛、design-audit）。下一页证明这些不是图上的线，是真实发生过的。

## 第 4 页 · 已闭合的环（实测证据，3 分钟，本页是主菜）

1. **证据环（S1）**：CC-BY 冻结语料真实纵切——4 hits / 2287 spans / **0 claims**。"摘要不产证据"是运行时行为，不是口号。
2. **假设环（S2–S3）**：模型（agnes-2.5-flash）真实提案 3 条候选，各带假设 + 可否证条件；IDEA-03 自报"超出 fixture 数据有效范围"——模型自己指出边界，而不是编材料学结论。G1 交回人工。
3. **设计环（S4）**：⛔ **第一次真实拦截**——模型起草的实验设计缺 stopping budget 字段，design-audit 以 blocker 退回，补齐后才 ready_for_g2。
4. **统计环（S5）**：⛔ **第二次真实拦截**——模型起草沿用 3 种子，统计门槛拒绝（配对种子 <4 不写任何文件）；改 4 配对种子后真实执行，**CI95 [-0.41, 0.51] 跨零 → 如实判"不可判定"**，附 power note（同效应 80% 功效需 263 种子）。IDEA-01 已走完官方路径的第一个可判定研究，并跨数据集复现（one_dataset_decided）。
5. **失效环（lineage）**：17 节点依赖图；改一行数据哈希 → **14 个下游节点判 stale，EXPORT BLOCKED**，旧签名不能复用。
6. **改进环（RSI）**：propose → dry-run → 领租约 → 真实 evaluator（BM25 vs MiniLM 对照）→ 确认；**两个 scope 闭合**；降级自动撤销、升级必须人签；S5 lease 在 iris 与 breast_cancer 通过。
7. **写作环（S8）**：写作包内容寻址绑定（pack_sha256 漂移即审计失败）；[REF-xx] 句级三态支持账本（42 supported / 0 partial）；GB/T 7714 草稿。
8. **委托环（autopilot）**：人写一次策略（scope/数据集/种子/有效期），agent 从主题跑到封包，每步 reason 带 `[delegated:autopilot]` + 策略 SHA-256，越界即停。

可引用的效果数字：护栏开火率 **8.1%**（21 包 37 条断言拦 3 条）；低功效判定反转率 9.68%；memory_on_gate_on 结论在 **4 数据集 64 种子全部同号**（generalizes=true）；E1 按断言原样精确率 4/4。

**怎么讲**：重点讲第 3、4 条——"系统赢了模型两次"。门禁不是装饰，是真拦过真实模型的输出。
