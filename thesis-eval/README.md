# thesis-eval —— 论文研究的 ESE 工作区（不进系统）

本目录承载毕业论文的实证软件工程（ESE）工作内容：**协议卡、外层分析脚本、ESE 报告**。它验证的对象是 `research_agent`（系统），但**不写进系统**——无新模块、无新命令、无发布同步。

## 目录

```
thesis-eval/
  protocols/   PROTO-*.md      # 人写预注册：RQ/假设/设计/分析计划/决策规则/效度预判/偏离日志
  analysis/    analyze_*.py    # 只读系统产物 → 配对区间/效应量 → 读数（不写回、不签核、不产生判定）
  reports/     EVAL-*.md       # ESE 八段报告：背景/RQ/设计/对象/变量/分析/结果/效度/复跑
```

## 纪律

1. **协议先于数据**：任何一场实验先写卡、学生签署、哈希冻结；偏离先登记。
2. **分析只读**：脚本读取系统产物（`memory/ab.json`、claim/EA/capsule 等），绝不写系统目录、不签核。
3. **判定不动**：结论判定仍只出自系统的 verdict-ledger / 人签；本目录只产出读数与报告。
4. **负结果照发**：supported/not_supported/underpowered 同等入报告，不修饰。
5. **复跑可核**：每份 EVAL 报告附复跑命令与产物路径；读数同步 `docs/fact-baseline.md`。

## 与系统的关系

- 系统 = 被验证对象 + 产物供给者（受控执行、结构化输出、复跑）。
- 本目录 = 验证方法（ESE）的实施地：协议卡、分析脚本、报告、效度清单。
