# 自进化 / RSI 百篇调研底账

这份目录保存 2026-10-24 的 100 篇文献快照，供 `30-` 与 `28-` 引用。

## 文件

- `bibliography.json`：100 条记录，含 arXiv ID、标题、作者、日期、簇、优化对象、反馈信号、读点、与仓库关系、摘要前 700 字与摘要 SHA-256。
- `catalog.md`：按五簇渲染的可读 Markdown 目录（100 行）。
- `README.md`：本说明。

## 方法

- 通过 `export.arxiv.org` API 做 36 组主题检索，得到 1,207 条候选；
- 按“是否真的改变系统/策略/记忆/技能/流程”筛选出 100 篇；
- 100 篇全部通过 arXiv `id_list` 重新拉取元数据，避免凭记忆写 ID；
- 摘要级通读；约 20 篇做机制/证据/边界二次核对；**未下载 PDF 全文、未复现、未运行作者代码**。

## 证据纪律

- 外部效果数字均为作者/机构口径；不得写成“本项目结果”；
- “hidden/OOD/regression”按论文原文语义记录，不替作者补证据；
- 书目中的 `abstract_sha256` 用于检查摘要是否被改动；
- 若发现元数据错误，以 arXiv 页面为准，并同步更新 `bibliography.json` 与 `catalog.md`。

## 复现检索

本次没有把检索脚本入库（临时脚本与缓存已清理）。复现时使用同一组关键词，或在 arXiv API 中以 `id_list` 直接核验本目录的 100 个 ID；建议至少保留 `published`、标题与摘要哈希三项。
